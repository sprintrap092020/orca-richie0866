# 🦈 Orca Script Hub — Community Archive (richie0866)

This repository contains a recovered backup of **Orca**, the iconic universal Roblox script hub created by **richie0866**. After the original developer deleted their GitHub account and all associated repositories, this archive preserves the work for historical purposes.

⚠️ **Disclaimer:** This repository is an unmaintained historical archive. I am not the original developer (richie0866), and I will not be updating, fixing, or providing support for these scripts.

---

## 📂 Repository Structure

*   `/orca-1.1.0(src)/` — The complete raw source code for Orca version 1.1.0.
*   `orca-1.1.1_compiled.txt` — The bundled/compiled production-ready script for version 1.1.1.

---

## 🚀 How to Execute (v1.1.1 Compiled)

To run the preserved v1.1.1 version in your Roblox environment, copy and paste this loadstring:

```lua
-- Orca v1.1.1 (Compiled Version)
loadstring(game:HttpGet("https://raw.githubusercontent.com/sprintrap092020/orca-richie0866/main/orca-1.1.1_compiled.txt"))()
```

**How it works:**
- This loadstring fetches the compiled Orca script directly from this repository
- Paste it into your Roblox executor (Synapse X, Krnl, ScriptWare, etc.)
- Press `K` to open/close Orca after execution
