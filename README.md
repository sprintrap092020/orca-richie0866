# 🦈 Orca Script Hub — Community Archive (richie0866)

This repository contains a recovered backup of **Orca**, the iconic universal Roblox script hub created by **richie0866**. After the original developer deleted their GitHub account and all associated repositories, these files were salvaged and archived for historical preservation.

⚠️ **Disclaimer:** This repository is an unmaintained historical archive. I am not the original developer (richie0866), and I will not be updating, fixing, or providing support for these scripts. Use at your own risk.

## 📂 Repository Structure

*   `/src_v1.1.0/` — The complete raw source code for Orca version 1.1.0.
*   `/baked_v1.1.1/` — The bundled/compiled production-ready script for version 1.1.1.
